# 砚池 · 私人提示词工作台

本地优先的轻拟物私人提示词仓库：沉淀、整理、调试、复用你的 AI 提示词。

## 特性

- **本地优先**：数据默认保存在本机浏览器（IndexedDB + 本地备份键），离线完整可用，可随时导出 JSON 备份。
- **多类型资产**：Agent / Chat / 生图 / 生视频 / 自定义，各自拥有结构化字段、快捷词与参数。
- **工作台调试**：`{{变量}}` 自动识别与填写、变量预设、实时合成预览、三种复制格式、试运行记录、版本存档与回滚。
- **精细仓库**：多仓库 / 分组 / 标签 / 收藏 / 置顶 / 智能视图 / 批量操作 / 回收站与撤销。
- **局域网同步**：连接任意 `ws://` / `wss://` 地址，命名空间过滤、心跳、自动重连、离线队列、冲突中心、可读日志。
- **轻拟物浅色界面**：纸感、柔和阴影、细腻高光，无深色模式。

## 使用

```bash
npm install
npm run dev      # 开发
npm run build    # 构建到 dist/
python launcher.py   # 一键启动本地服务并自动打开浏览器
```

启动器只使用 Python 标准库，无需安装依赖；启动失败时会给出温和、可操作的提示。
